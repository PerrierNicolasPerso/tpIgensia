 Guide de contribution
Merci de contribuer au projet tpIgensia.

Flux de travail
1. Créer une branche
Toute modification doit être réalisée dans une branche dédiée à partir de main.

Exemples :

git switch -c feat/ma-fonctionnalite
git switch -c fix/correction-bug
git switch -c docs/amelioration-doc
